# 🌡️ Temperature Converter

## 📌 Project Overview

The **Temperature Converter** is a simple, user-friendly, and interactive web application designed to convert temperatures between Celsius, Fahrenheit, and Kelvin. It provides a quick and convenient way to calculate temperature values using an easy-to-use interface.

This project is developed using HTML, CSS, and JavaScript. It demonstrates the practical use of JavaScript calculations, DOM manipulation, event handling, and responsive web design.

## ✨ Features

- 🌡️ Convert temperatures between Celsius, Fahrenheit, and Kelvin.
- 🔄 Quick and accurate temperature conversions.
- 🎨 Clean and attractive user interface.
- ⚡ Instant conversion results.
- 📱 Responsive design for different screen sizes.
- 🖥️ Easy-to-use input fields and selection options.
- 🚀 Simple and lightweight application.

## 🛠️ Technologies Used

- **HTML5** – Creates the structure of the application.
- **CSS3** – Provides styling, layout, and visual appearance.
- **JavaScript** – Handles temperature conversion calculations and interactive functionality.

## 🔄 Temperature Conversion Formulas

The application uses the following mathematical formulas:

| Conversion | Formula |
|---|---|
| Celsius to Fahrenheit | (°C × 9/5) + 32 |
| Fahrenheit to Celsius | (°F − 32) × 5/9 |
| Celsius to Kelvin | °C + 273.15 |
| Kelvin to Celsius | K − 273.15 |
| Fahrenheit to Kelvin | (°F − 32) × 5/9 + 273.15 |
| Kelvin to Fahrenheit | (K − 273.15) × 9/5 + 32 |

## 🚀 How to Run the Project

Follow these steps to run the Temperature Converter:

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Locate the HTML file.
4. Open the HTML file in your web browser.
5. Enter a temperature value.
6. Select the temperature units.
7. Click the convert button to view the result.

## 💡 How It Works

1. Enter the temperature value in the input field.
2. Select the original temperature unit.
3. Choose the temperature unit you want to convert into.
4. Click the conversion button.
5. The application calculates and displays the converted temperature.
